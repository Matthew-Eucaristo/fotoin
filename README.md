# Fotoin

Foto dia persis seperti referensi. Pick a reference photo (Pinterest, IG, or a
sample), then shoot with the reference as a ghost overlay and pose skeleton,
a live match meter, coaching hints ("Mundur sedikit", "Geser HP ke kanan"),
and auto-capture when the pose matches. Runs fully on-device (Apple Vision on
iOS, Google ML Kit on Android).

```bash
npm install
npx expo run:ios       # or: npx expo run:android
```

See `AGENTS.md` for the stack, architecture, and gotchas.
