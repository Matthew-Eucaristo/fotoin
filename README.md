# Fotoin

Foto dia persis seperti referensi. Pick a reference photo (Pinterest, IG, or a
sample), then shoot with the reference as a ghost overlay and pose skeleton,
a live match meter, coaching hints ("Mundur sedikit", "Geser HP ke kanan"),
and auto-capture when the pose matches.

Runs fully on-device (Apple Vision on iOS, Google ML Kit on Android).

```bash
flutter pub get
flutter run -d <device>
```

See `AGENTS.md` for architecture and gotchas.
